# 产品视频导演 · 1.0.0

根据「产品资料 + 想要的风格」，推荐适用场景、设计故事、自动拆段，并分别写出每段完整的首帧、必要关键帧、尾帧、视频动态与转场提示词。默认中文，覆盖全品类；人物、动物、IP 和超现实元素均为可选。

内置 **60 个场景、180 套风格方案**，支持改编、新增、保真润色与锁定片段返修。本技能负责策划和提示词，不自动生成图片或视频。

## 三种调用方式

**从产品与风格开始：**

```text
使用 $product-video-director。
产品资料与参考图如下，目标风格是温暖、安静、自然摄影。
先推荐优先适配和探索方向的场景，说明理由，再给三个不同故事方向。
不要编造产品功能。等我选定方向后展开。
```

**把确定的故事拆成制作包：**

```text
使用 $product-video-director。
我的故事已经确定，请直接按事件和生成难度拆段，建议时长。
每段提供独立完整的首帧、必要关键帧、尾帧、动态与跨段衔接提示词。
复杂镜头给简化备选，最后保存完整 Markdown 和 PDF。
```

**返修已有片段：**

```text
使用 $product-video-director。
读取旧方案和素材，第 1、3 段已满意并锁定，只重做第 2 段。
保留两侧边界状态，重写第 2 段完整帧提示词和动态，检查前后衔接。
给更稳的备选，保存新版本，暂不上传。
```

只需润色时，可直接要求「意思不变，保留所有事实、数字、动作与约束，优化以下提示词」。

## 保存与使用边界

正式方案先本地保存，只有明确要求同步 GitHub 时才上传个人项目。通用技能库与个人项目分开，不默认上传视频原件；继续项目时读取实际档案，没有后台记忆或自动同步。

五个选定 MIT 项目的适配说明、原始许可、场景库、脚本和验证记录均在完整 ZIP 内。脚本与提示词任务经过检查；实际图像、视频效果及具体生成平台能力仍需在制作中验证，不保证零漂移或百分之百还原。
