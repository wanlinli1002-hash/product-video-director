# 产品视频导演 · 1.3.0

把视频想法、产品图、人物图或角色描述，整理成能够逐段制作的视频方案：按需澄清需求，推荐适配场景，设计故事与转场，准备必要参考素材，再交付**每段可以整块复制的完整视频提示词**。

默认中文，覆盖全品类与多种风格。人物、动物、动漫角色和超现实元素都可选，也支持没有产品的角色短片。内置 **60 个场景、180 套风格方案**，支持改编与扩展。本技能负责策划、提示词和制作指导，不自动生成图片或视频。

## 新版怎样帮你制作

1. **理解需求。** 先读取已给出的想法和素材，只补问影响方案的少量问题；已有场景、氛围或故事直接沿用，不强制长问卷。
2. **推荐场景与故事。** 未选场景时给适配方向和理由；需要完整创意时提供有实质区别的故事方向，再按事件和制作难度分段。
3. **选择合适的工作流。** 根据现有素材与当前工具能力，评估多参考直接生成、已有视频局部编辑、动作或表演驱动、多镜头、延长，以及剪辑合成。首帧、关键帧、尾帧控制仍保留为按需选项，不再默认要求每段制作三类图片。
4. **先准备每段素材。** 列明已有可复用、必须新增、可选及无需新增的素材。需要新参考图时，给完整生图提示词、参考用途、文件名与验收要点；共用素材生成一次即可复用。
5. **直接复制执行。** 说明本段应附哪些素材及其作用，再给已经合并身份、场景、风格、动作、运镜和保持项的视频提示词，不要求用户拼接公共段落。
6. **检查连续性并返修。** 追踪产品与角色身份、接触关系、道具归属、空间方向和段间状态；保护满意片段，只修改允许范围，复杂镜头给简化备选。

3–5 分钟等长片会按需要建立故事章节、资产母版、连续性记录和试片顺序。段数、时长与参考数量服从本次任务，不固定为九宫格或统一模板。

## 三种调用方式

**从想法或素材开始：**

```text
使用 $product-video-director。
我想为附件中的产品做视频，风格是温暖、安静、自然摄影。
先理解我已有的素材，必要时问少量问题，推荐适合的场景并说明理由。
不要编造产品功能。如果信息已经足够，直接推进。
```

也可以提供人物图、动物图、动漫角色或纯文字想法；没有产品时无需加入营销内容。

**把确定的故事展开为制作包：**

```text
使用 $product-video-director。
故事已经确定：窗边晨光揭示产品，切到标志细节，再转到庭院，最后展示全貌。
按事件与制作难度分段，建议时长，根据已有素材选择合适工作流。
每段先告诉我需要准备哪些参考素材；必要新图给完整生图提示词。
再说明要附哪些文件，给我可以整块复制的视频提示词，不要让我自己组装。
不默认做首尾图，复杂镜头给简化备选，最后保存完整 Markdown 和 PDF。
```

**只返修失败片段：**

```text
使用 $product-video-director。
读取旧方案和我提供的素材，第 1、3 段已满意并锁定，只重做第 2 段。
问题是交接产品时出现重复物体和手指穿模。
保留前后段的实际状态，优先评估局部编辑或替换失败镜头。
给完整执行提示词、必要素材准备和更稳的备选，保存新版本，暂不上传。
```

只调整措辞时，可要求“保真润色，保留所有事实、动作、数字与约束，不新增剧情”。

## 保存与验证边界

正式方案先本地保存，只有明确要求同步 GitHub 时才上传个人项目。通用技能与个人项目档案分开，不默认上传视频原件；没有后台记忆或自动同步。

技能结构、脚本行为、指南排版和有限文字试用已有验证记录，见 ZIP 内 `tests/VALIDATION.md`。这些检查不等于实际生成效果测试。具体平台与模式的输入、参考数量、编辑和控制能力需按当前入口核实；不保证零漂移、零穿模或百分之百还原，也不把创作者精选案例当作成功率统计。
