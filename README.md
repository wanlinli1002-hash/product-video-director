# 产品视频导演 · 1.4.0

把视频想法、产品图、人物图或角色描述，整理成能够逐段制作的视频方案：理解目标、推荐或沿用场景，设计完整故事、分段与转场，交付各阶段资产设定图提示词，以及**每段可以整块复制的完整视频提示词**。

默认中文，覆盖全品类与多种风格。人物、动物、动漫角色和超现实元素都可选，也支持没有产品的角色短片。内置 **60 个场景、180 套风格方案**，支持改编与扩展。本技能负责策划、提示词和制作指导，不自动生成图片或视频。

## 1.4.0 新增要求

1. **缺少时长，先询问。** 为整片策划或新片段制作时，没有提供对应时长就先问。已有精确时长、范围或明确授权“时长由你决定”时直接采用；不会从“短片”“其他你定”等说法推断时长授权。纯场景灵感、静态图或保真润色仍按请求范围处理。
2. **第一份正式方案就给完整脚本。** 从开场到收尾列齐所有分段、时长、画面、动作、对白或旁白、声音和接法。已有方向直接展开；未定方向可选择推荐主案后完成第一版。只有用户明确要求先比较方向时，才停留在方向比较。
3. **一次交齐各阶段资产设定图词。** 覆盖本片涉及的人物、动物或 IP、场景、产品及物品，按换装、年龄、天气、时段、开合、受损等实际变化列出版本与适用片段。已有素材可复用，未改变的资产不重复制作；真实产品的未知结构与功能不虚构。
4. **一次交齐项目所需制作提示词。** 逐段视频，以及适用的转场、插镜、环境与合成图层、旁白、音乐、音效、局部修复和简化备选均纳入同一份文档。用覆盖清单核对脚本、资产阶段、图像卡、视频词及依赖；不留下已知缺口让用户反复追问，也不堆积与本片无关的变体。

缺时长时的澄清回复不算第一份正式方案。正式完整方案同时保存可编辑 Markdown 与 PDF；聊天容纳不下时，完整内容写入文件，而不是只交前几段。设定图提示词的交付不取决于视频模式是否需要图片，也不代表每段都必须生成和上传所有图片。

## 制作流程

- **按需澄清与推荐场景。** 先读取已有想法、素材和限制；已有场景与氛围直接沿用，没有时推荐并说明适配理由，不强制长问卷。
- **按故事与难度分段。** 建立脚本、身份与资产版本、连续性状态，选择适合当前素材和工具的工作流。3–5 分钟等长片按需要增加章节、素材预演和重点试片顺序。
- **说明每段素材准备。** 区分已有可复用、必须新增、可选和无需新增；列清输入、用途、文件名与验收。共用母版制作一次，阶段变化明确派生关系。
- **直接复制执行。** 每个视频提示词已合并本段身份、场景、风格、动作、运镜与保持项；素材绑定说明放在旁边，不要求用户拼接公共段落。
- **连续性与局部返修。** 追踪接触、承重、道具归属、空间方向和前后段状态；保护满意片段，只修改允许范围，复杂镜头提供可直接执行的简化备选。

可选工作流包括多参考直接生成、已有视频局部编辑、动作或表演驱动、多镜头、延长和剪辑合成。首帧、关键帧、尾帧控制保留为按需选项，不默认要求每段制作三类图片。段数、时长、参考数量和可用能力按本次任务及实际入口确定，不固定为九宫格或统一模板。

## 三种调用方式

**从想法或素材开始：**

```text
使用 $product-video-director。
我想为附件中的产品做 45 秒横版视频，风格是温暖、安静、自然摄影。
读取已有素材，推荐适合的场景并说明理由，选择最适合的一案。
不要编造产品功能。信息够用时，直接交第一版完整脚本、
各阶段人物／场景／物品图像提示词，以及逐段可复制的视频和相关制作提示词。
```

也可以提供人物图、动物图、动漫角色或纯文字想法；没有产品时无需加入营销内容。

**把确定的故事展开为制作包：**

```text
使用 $product-video-director。
故事已经确定：窗边晨光揭示产品，切到标志细节，再转到庭院，最后展示全貌。
总时长由你根据故事决定，请说明本版时长，并按事件和制作难度分段。
第一版给完整剧本，交齐各阶段人物、场景、产品与道具的详细设定图词。
每段说明需要准备和附上的素材，再给能整块复制的视频提示词，不让我自行拼接。
不默认制作首尾图；补齐适用的转场、声音与简化备选，最后保存完整 Markdown 和 PDF。
```

**只返修失败片段：**

```text
使用 $product-video-director。
读取旧方案和我提供的素材，第 1、3 段已满意并锁定，只重做第 2 段。
问题是交接产品时出现重复物体和手指穿模，沿用原段时长。
保留前后段的实际状态，优先评估局部编辑或替换失败镜头。
给完整执行提示词、必要素材准备和更稳的备选，保存新版本，暂不上传。
```

只调整措辞时，可要求“保真润色，保留所有事实、动作、数字与约束，不新增剧情”。单镜头、灵感和局部修改不会强制扩大为整片制作。

## 保存与验证边界

正式方案先本地保存，只有明确要求同步 GitHub 时才上传个人项目。一次同步授权不代表之后自动上传。通用技能与个人项目档案分开，不默认上传视频原件；没有后台记忆或自动同步。

验证记录见 ZIP 内 `tests/VALIDATION.md`。本版完成结构与文件一致性检查、指南排版检查和有限的独立文字试用；保留已有辅助脚本测试记录。**未做实际图片或视频生成效果验证**，文字试用不等于出片成功率测试。

具体平台与模式的输入、参考数量、编辑和控制能力需按当前入口核实；不保证零漂移、零穿模或百分之百还原，也不把创作者精选案例当作成功率统计。详细提示词与素材分工用于减少歧义，实际生成结果仍需检查。
